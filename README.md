# Yulduzlar Akademiyasi TITAN ULTIMATE

Frontend-first ta’lim platformasi.

## Yangi modullar
- AI laboratoriya demo
- Code Lab: HTML/CSS/JS live preview
- Exam Arena: timer, score, XP
- Local login/profile
- Admin Console demo
- Analytics, Focus Timer, Tasks, Notes, Planner
- Dark/Light theme, animations, responsive UI
- localStorage + JSON backup

## Ishga tushirish
`index.html` ni Chrome/Edge’da oching. Backend talab qilinmaydi.

## Eslatma
AI va admin funksiyalari ushbu versiyada frontend demo/local rejimda ishlaydi; real server/AI API ulash uchun backend endpoint kerak bo‘ladi.
